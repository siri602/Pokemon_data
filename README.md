# Pandas Through Pokemon Dataset

Learning pandas by working through the Pokemon dataset, following Keith Galli's YouTube tutorial.

## What's in this repo

- `pokemon_data.csv` — the dataset
- Jupyter notebook with all the pandas code

## What I practiced

- Reading data with `read_csv`
- Viewing data — `head()`, `tail()`, `columns`, `iloc`, `loc`
- Filtering rows with conditions
- Sorting values by one or more columns
- Grouping data with `groupby`
- Adding and modifying columns
- Saving the cleaned/modified data back to a file

## Tools

- Python
- pandas
- Jupyter Notebook

## Credit

Tutorial by [Keith Galli](https://www.youtube.com/c/KeithGalli). Dataset is the classic Pokemon CSV used in his pandas video.

Learning pandas from scratch, doing it hands-on instead of just watching.
